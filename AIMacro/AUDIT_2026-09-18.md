## Still not CPython

- Comparison/`and`/`or`/`in` still print as `0`/`1` (`print(1 == 1)` is `1`).
- Multi-key dict print order is `Hash.Keys` order.
- `type(x) is int` cannot work (`type` is a TypeID integer).
- No closures, `lambda`, `async`, `**kwargs`, `set`.
- `raise` is software pending + `Fork`, not stack unwind.
- `py2aim` only inserts braces; it does not implement missing syntax.
