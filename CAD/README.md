# AILang CAD

The CAD project is part of the [AILang self-hosting repository](https://github.com/AiLang-Author/Ailang-Self-Hosting-). This directory contains the CAD application and supporting code, examples, and tests. The project is under active development, and changes are expected as work continues.

## Help improve the project

I’m pushing a lot of changes this week and welcome feedback from people trying the project. Useful contributions include:

- Bug reports with steps to reproduce
- UI fixes and suggestions that make the application easier to use
- Usability concerns, confusing interactions, or rough edges
- Workflow feature ideas and other practical improvements
- Focused fixes, tests, and documentation updates

You don’t need to submit code to help. Clear reports about what you tried, what you expected, and what happened are valuable. For UI or workflow feedback, screenshots or a short example are helpful when available.

### Reporting a bug or suggesting an improvement

[Open an issue](https://github.com/AiLang-Author/Ailang-Self-Hosting-/issues) and include as much of the following as you can:

- What you were doing and how to reproduce the problem
- What you expected to happen and what actually happened
- Your operating system and relevant project version or commit
- Screenshots, sample files, or error output, if applicable

Please search existing issues first so related reports and discussions stay together. For security-sensitive concerns, follow the private reporting guidance in the repository’s [contributing guide](../CONTRIBUTING.md).

### Contributing changes

Pull requests for focused fixes, UI improvements, tests, and documentation are welcome. Before starting a large change, open an issue to discuss the idea and make sure it fits the project’s direction. Please read the repository’s [contributing guide](../CONTRIBUTING.md) and [contributor license terms](../CLA.md) before submitting work; they describe the project’s contribution and licensing model.

## Donations

There is no donation button or payment link set up for this project right now. If donations are enabled later, the details will be added here. The CAD work may eventually move to its own dedicated repository; for now, this is its home within the AILang repository.
