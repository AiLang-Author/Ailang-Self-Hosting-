# AILang Compiler — 07: Support Systems

## Overview

Beyond the core compile/emit/output pipeline, the compiler includes support systems for debugging, linking, floating-point, optimization, and OS-portable syscall dispatch.

---

## 1. DEBUG SYSTEM (3 files, ~43KB)

### 1.1 Architecture
```
Debug/
├── Library.CCompileDebug.ailang   (29KB) — debug info generation
├── Library.CDebugTypes.ailang     (5KB)  — debug type constants
└── X86/
    └── Library.CEmitDebugX86.ailang (8KB) — x86 debug emission
```

### 1.2 Debug Info Generation
```
CompileDebug_EmitLineInfo(file, line, col) → void
    Record source location for current code position
    Used for debugger integration and error reporting

CompileDebug_EmitFunctionDebug(func_name) → void
    Mark function boundary in debug info

CompileDebug_EmitVariableDebug(name, offset, type) → void
    Record variable location for debugger

CompileDebug_Finalize() → void
    Write debug info to separate .debug section or embedded notes
```

### 1.3 DebugPerf System
```
DebugPerf — Block-based performance measurement:
    DebugPerf { "name" { ... code ... } }
    Compiles as: save timestamp, run code, compute delta, report
    Uses RDTSC or clock_gettime for timing
```

## 2. LINK SYSTEM (5 files, ~42KB)

### 2.1 Architecture
```
Link/
├── Library.Dispatch.ailang          (2KB)  — link-time dispatch
├── Core/
│   ├── Library.RelocTable.ailang    (1.3KB)— relocation table
│   └── Library.SymbolTable.ailang   (1.5KB)— symbol table
└── OS/Linux/
    ├── Library.ELFKernelModule.ailang (34KB)— kernel module support
    └── Library.KernelABI.ailang      (1.8KB)— kernel ABI constants
```

### 2.2 Link-Time Features
```
SymbolTable:
    - Tracks exported symbols (Function, SubRoutine, FixedPool)
    - Tracks imported symbols (LibraryImport)
    - Resolves cross-module references

RelocTable:
    - Records positions needing address patching
    - Supports: R_X86_64_64, R_X86_64_PC32, R_X86_64_32

KernelModule:
    - Builds Linux kernel modules (.ko files)
    - Handles ExternalKernelFunction declarations
    - Kernel ABI versioning
```

## 3. FPU SYSTEM (8 files, ~120KB)

### 3.1 Architecture
```
Compile/FPU/
├── Library.FPUTypes.ailang            (4KB)  — FPU type constants
└── X86/
    ├── Library.FPUCompileX86MemOps.ailang   (13KB) — memory ops
    ├── Library.FPUCompileX86SSE.ailang      (24KB) — SSE compilation
    ├── Library.FPUCompileX86String.ailang   (21KB) — string conversion
    ├── Library.FPUCompileX86Trans.ailang    (10KB) — transcendental
    ├── Library.FPUEmitX86MemOps.ailang      (15KB) — emit memory ops
    └── Library.FPUEmitX86SSE.ailang         (14KB) — SSE emission
```

### 3.2 Floating Point Support
```
Uses SSE/SSE2 instruction set for floating-point operations:
    - XMM0-XMM7 registers for FP values
    - MOVSS/MOVSD for load/store
    - ADDSS/ADDSD, MULSS/MULSD, etc. for arithmetic
    - CVTSI2SS/CVTSI2SD for int→float conversion
    - CVTSS2SI/CVTSD2SI for float→int conversion

Transcendental functions (sin, cos, sqrt, etc.):
    Implemented via inline series expansions or libm calls
```

## 4. OPTIMIZATION SYSTEM (2 files, ~51KB)

### 4.1 CCompilerOptimizer (20KB)
```
Compile-time peephole optimizations:
    - Constant folding: 2+3 → 5 at compile time
    - Dead store elimination: remove stores never loaded
    - Strength reduction: x*2 → x+x
    - Jump threading: chain unconditional jumps
    - Null check elimination: remove redundant null checks

Pattern:
    Before emitting, check if expression can be evaluated at compile time
    If yes, emit immediate load instead of computation sequence
```

### 4.2 COptimizeHoist — Loop Hoisting (31KB)
```
Loop-invariant code motion:
    Identify expressions inside loops whose values don't change
    Move them before the loop
    
    Example:
        WhileLoop i < n {
            x = a + b          ← a+b is loop-invariant
            result = x * i
        }
    
    Optimized to:
        x = a + b              ← hoisted
        WhileLoop i < n {
            result = x * i
        }
```

## 5. SYSCALL DISPATCH SYSTEM (2 files, ~303KB)

### 5.1 CSysDispatch (285KB) — AUTO-GENERATED

The largest single file in the compiler. Generated by `generate_sysdispatch.py` from syscall tables.

```
Generated header:
    // DO NOT EDIT MANUALLY - Regenerate with:
    //   python3 generate_sysdispatch.py -o ../Library.CSysDispatch.ailang

Pattern for every syscall:
    Function.Sys_Read {
        Body: {
            // --- LINUX ---
            IfCondition EqualTo(Emit.os, OS.LINUX) ThenBlock: {
                Emit_MovRaxImm64(LinuxSys.READ)   // syscall 0
                Emit_SysInstr()
            }
            // --- HAIKU ---
            IfCondition EqualTo(Emit.os, OS.HAIKU) ThenBlock: {
                Emit_MovRaxImm64(HaikuSys.READ)   // syscall 140
                Emit_SysInstr()
            }
        }
    }
```

### 5.2 Syscall Tables

**CSyscallTable (18KB):** Maps logical syscall names to OS-specific numbers.

**Generator tools:**
```
syscall_generator_tools/
├── generate_sysdispatch.py     — main generator
├── syscall_table_linux.py      — 450+ Linux syscalls  
└── syscall_table_haiku.py      — 25+ Haiku syscalls
```

### 5.3 Supported Syscalls (300+ functions)

```
PROCESS:     Sys_Exit, Sys_Fork, Sys_Execve, Sys_Getpid, Sys_Clone
MEMORY:      Sys_Mmap, Sys_Munmap, Sys_Mprotect, Sys_Brk
FILE:        Sys_Open, Sys_Read, Sys_Write, Sys_Close, Sys_Lseek,
             Sys_Stat, Sys_Fstat, Sys_Access, Sys_Rename, Sys_Unlink,
             Sys_Mkdir, Sys_Rmdir, Sys_Chmod, Sys_Chown, Sys_Fcntl
SOCKET:      Sys_Socket, Sys_Bind, Sys_Listen, Sys_Accept,
             Sys_Connect, Sys_Shutdown, Sys_Setsockopt
TIME:        Sys_Nanosleep, Sys_ClockGettime, Sys_Gettimeofday
THREAD:      Sys_Clone, Sys_Futex, Sys_SchedYield
MISC:        Sys_Getrandom, Sys_Uname, Sys_Getuid, Sys_Getgid
```

## 6. KERNEL MODULE SUPPORT

### 6.1 ELFKernelModule (34KB)
```
Builds Linux kernel modules (.ko files):
    - Kernel module ELF structure
    - Module init/exit functions
    - Kernel symbol resolution
    - Module parameter support
    - License/module info sections

ExternalKernelFunction declaration:
    ExternalKernelFunction.printk {
        Input: fmt: Address, ...
        Output: Integer
    }
    // Resolved at insmod time, not at compile time
```

### 6.2 KernelABI (1.8KB)
```
Kernel ABI version constants
System call convention for kernel modules  
Register mapping for kernel-mode execution
```
